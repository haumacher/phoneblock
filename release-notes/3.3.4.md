# PhoneBlock 3.3.4

*unreleased*

## API

- **Partner report exchange.** New feed `GET /api/partner/reports` of the spam
  reports made by PhoneBlock users (partner token only), and a daily import of
  the spam reports of the partner service Nize.

## Fixes

- **Removing a number on the settings page** now also takes back the user's
  vote and comment, as the API already did. Blocking, removing and blocking a
  number again no longer counts as two votes.

# PhoneBlock 3.2.7

*unreleased*

## Answerbot

- **Self-hosted answerbot follows your account settings (#570).** The Docker/standalone answerbot now uses the "Mindest-Konfidenz" and the wildcard option from your PhoneBlock account settings instead of a fixed threshold of 4 votes. Set `min-votes` / `wildcard` (`MIN_VOTES` / `WILDCARD` in Docker) only to override them locally. The effective values are logged at startup.

## API

- `/api/account` returns `minVotes` and `wildcards`.

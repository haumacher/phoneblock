# PhoneBlock 3.2.7

*2026-10-11*

## Answerbot

- **Self-hosted answerbot follows your account settings (#570).** The Docker/standalone answerbot now uses the "Mindest-Konfidenz" and the wildcard option from your PhoneBlock account settings instead of a fixed threshold of 4 votes. Set `min-votes` / `wildcard` (`MIN_VOTES` / `WILDCARD` in Docker) only to override them locally. The effective values are logged at startup.

## Server

- **One WAR for every deployment (#577).** OAuth credentials and the donation bank account are no longer compiled into the WAR; they are read at startup via JNDI (`oauth/google/id`, `oauth/google/secret`, `bank/receiver`, `bank/account`, `bank/bic`). The context path is taken from the deployment, and the embedded answerbot UI adapts its base path when served. **Operators: add the `oauth/*` and `bank/*` entries to the Tomcat `context.xml` before deploying 3.2.7**, otherwise Google login and the donation QR code are disabled (the server logs which settings are missing).

## Deployment

- Release WARs are built by GitHub Actions and attached to the GitHub release; `phoneblock/bin/pb-deploy` installs them on the server with a database backup and rollback (#578).

## API

- `/api/account` returns `minVotes` and `wildcards`.

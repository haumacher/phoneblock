# PhoneBlock 3.3.1

*unreleased*

## Server

- **CardDAV clients find the address book on their own (#524).** `/.well-known/carddav` (below `/phoneblock/` and below `/phoneblock/contacts/`) now redirects with `301` to the CardDAV root `/phoneblock/contacts/` instead of answering `404`, so clients like macOS/iOS Contacts, DAVx5 and Thunderbird can set up the address book from the server address alone (RFC 6764).

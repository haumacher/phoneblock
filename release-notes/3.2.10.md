# PhoneBlock 3.2.10

## Server

- **The search page explains why a number is not accepted.** Instead of a generic "not a phone number", it names the reason: unknown country code, too few digits for the area or service code (e.g. `032`), trunk prefix after the country code, missing trunk prefix in national format, or too short. For numbers that cannot exist, it hints that the caller ID was probably spoofed.

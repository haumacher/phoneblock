# PhoneBlock 3.2.9

*2026-10-17*

## Server

- **Rating a number no longer fails with an error when it is submitted twice at the same time (#520).** The second submission is treated as a repeated rating instead of answering HTTP 500; the same applies to call reports and CardDAV blocks.
- **E-mail verification works again for addresses used by more than one account (#523).** Login by e-mail picks the most recently used account; registration and e-mail change no longer create a second account for an address that is already in use.
- **No more credentials or personal data in the server log (#525, #528).** API tokens, Basic-auth headers, typed logins, names, e-mail addresses and rating comments are replaced by lengths, internal ids or a short fingerprint; repeated token failures from one broken client are logged once per 10 minutes with a count.

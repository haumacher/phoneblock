# PhoneBlock 3.3.3

*unreleased*

## Web site

- **FAQ: blocked calls on the mailbox.** A new entry explains why callers
  blocked by the Android app can still reach the mailbox (the network reports
  busy and forwards on busy) and how to switch off only busy forwarding with
  the GSM codes, and how to undo it (#549).
- **Statistics: Active dongles by platform.** A new chart on the statistics
  page counts the PhoneBlock Dongles that were active in the last 30, 60 and
  90 days, grouped by platform (ESP32, ESP32-C3, ESP32-S3, Linux, Home
  Assistant, Docker). Each dongle counts once. The PhoneBlock Dongle line in
  the installations chart is now shown by default (#763).

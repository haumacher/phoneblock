# PhoneBlock 3.3.2

*2026-11-13*

## Web site

- **Dongle page: self-hosting.** A new section shows how to run the dongle
  software without the hardware: as a Home Assistant app, as the Docker image
  `phoneblock/answerbot2` or as a Debian package (#751).
- The dongle page no longer advises setting a ring delay on the Fritz!Box (#738).
- The answering-machine page points self-hosters to `phoneblock/answerbot2`
  instead of the retired Java image.
- Translated pages no longer show broken markup such as `<X2>` or `</x1` in
  place of a link or emphasis (#751, #754).
- **Installation videos.** The dongle page and the blocklist setup page show
  their installation video. It is loaded from YouTube only after a click; until
  then the page shows a preview image of its own (#755).

## Security

- The Content-Security-Policy and `X-Content-Type-Options` headers now reach
  the web pages, not only static files: their filters were registered by
  annotation and ran behind the page renderer on Tomcat. Inline styles and
  scripts the policy blocks were moved into the style sheet and script files.
- Style sheets and scripts are loaded with the version as parameter, so a
  release is not combined with cached files of the previous one.

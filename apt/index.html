PhoneBlock Dongle für Linux

Der PhoneBlock-Anrufbeantworter als Dienst auf einem Raspberry Pi oder einem anderen Debian/Ubuntu-Rechner im Heimnetz: gleiche Web-Oberfläche und gleiche Version wie die Firmware des ESP32-Dongles. Diese Seite ist das APT-Repository des Pakets phoneblock-dongle.

Installation

Die Suite richtet sich nach dem System:

SystemSuite
Debian 12, Raspberry Pi OS (Bookworm), Ubuntu 22.04bookworm
Debian 13, Raspberry Pi OS (Trixie), Ubuntu 24.04 und neuertrixie

Der Kanal stable enthält nur Releases, beta zusätzlich Vorabversionen (wie die Update-Kanäle der Dongle-Firmware). Beispiel für Bookworm und beta:

sudo curl -fsSLo /usr/share/keyrings/phoneblock-dongle.gpg \
  https://haumacher.github.io/phoneblock/apt/phoneblock-dongle.gpg
echo "deb [signed-by=/usr/share/keyrings/phoneblock-dongle.gpg] https://haumacher.github.io/phoneblock/apt bookworm beta" \
  | sudo tee /etc/apt/sources.list.d/phoneblock-dongle.list
sudo apt update
sudo apt install phoneblock-dongle

APT wählt die Architektur selbst (amd64, arm64 und armhf werden veröffentlicht). Welche Version in welchem Kanal liegt, zeigt die Tabelle unten.

Einrichtung

Dienst starten, Fritz!Box und PhoneBlock-Anmeldung in der Web-Oberfläche einrichten, Port, Einstellungen und Fehlersuche: Anleitung zum Linux-Dienst.

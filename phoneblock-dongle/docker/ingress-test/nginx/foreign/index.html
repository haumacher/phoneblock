Eine andere Website

Steht für phoneblock.net: Ein Link (oder eine Weiterleitung) von hier in den Ingress-Pfad ist eine Cross-Site-Navigation. Der Browser schickt das SameSite=Strict-Cookie dann nicht mit, und der Ingress antwortet 401: Unauthorized — wie Home Assistant beim Rücksprung nach der Anmeldung (#619, Hindernis 3).

Diese Seite muss unter einem anderen Hostnamen geöffnet sein als die Schale (z. B. hier localhost, die Schale unter der LAN-IP); der Port zählt nicht.

Diesem Link folgen → 401 erwartet.

Dieselbe Adresse in die Adressleiste kopiert → die Oberfläche erscheint.

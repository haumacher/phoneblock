# PhoneBlock Dongle 1.7.0

*unreleased*

## Added

- **Two new buttons in the call list.** A caller the Fritz!Box does not know
  shows up without a name. "＋ Kontakt" writes them into a Fritz!Box phonebook,
  so the phone shows the name on the next call and the dongle stops asking
  PhoneBlock about them. "⚠ Spam" reports the number to PhoneBlock, optionally
  with a short reason. A contact is never offered as spam — a phonebook entry
  already overrules every blocklist on the dongle.

- **Choose which phonebook new contacts go to.** Asked once, changeable under
  "Telefonbuch für neue Kontakte". Phonebooks that synchronise with an online
  address book (CardDAV, Google) are shown but cannot be selected: the
  Fritz!Box rejects writes to them. Needs a dongle set up with the Fritz!Box
  wizard.

## Fixed

- A rating comment containing a quotation mark would have produced a malformed
  request. Comments are now escaped correctly.

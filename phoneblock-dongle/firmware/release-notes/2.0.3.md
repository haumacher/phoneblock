# PhoneBlock Dongle 2.0.3

*unreleased*

- **Display on the LilyGO T-Display V1.1 (#708).** The classic ESP32
  firmware can now drive the 240x135 screen of this board: the logo with
  the spam badge, and the caller during a call, as on the T-Dongle-S3.
  Select "LilyGO T-Display V1.1" under System ▸ Board (or tick "Display
  einschalten"); the display is off by default on the ESP32. The backlight
  goes off a minute after boot or a call instead of dimming. Not offered on
  the EGBO dongle (ESP32-PICO-D4), whose flash sits on a display pin.

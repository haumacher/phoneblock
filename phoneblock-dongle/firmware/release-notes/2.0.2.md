# PhoneBlock Dongle 2.0.2

*2026-11-13*

- The classic ESP32 dongle no longer restarts after nearly every blocked
  spam call: reporting the call to PhoneBlock overran the stack of its
  worker since 2.0.0. The same fault could crash the next caller check.
- The token test no longer reports "Token was rejected" when PhoneBlock is
  just unreachable or has a server error; only a real rejection says so.
